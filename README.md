# 📌 Task Manager – Full Stack Application

🚀 A modern full-stack Task Manager web application built using **React, Node.js, Express, and MongoDB**.  
This app helps users efficiently manage tasks with features like filtering, prioritization, and real-time updates.

---

# 🌟 Features

- ✅ Add, edit, and delete tasks  
- ✅ Mark tasks as completed (with confirmation)  
- ✅ Filter tasks (All / Pending / Completed)  
- ✅ Search tasks 🔍  
- ✅ Set priority levels (Low / Medium / High)  
- ✅ Add due dates 📅  
- ✅ Completed tasks automatically move to bottom  
- ✅ Basic login (using local storage)  
- ✅ Stats dashboard 📊  
- ✅ Responsive and modern UI

# ⚙️ Installation & Setup

## 🔹 1. Clone the repository
```bash
git clone https://github.com/your-username/task-manager-fullstack.git
cd task-manager
```

---

## 🔹 2. Backend Setup

```bash
cd backend
npm install
```

### Start backend server:
```bash
npm start
# or
npx nodemon server.js
```

Runs on:  
👉 http://localhost:5000

---

## 🔹 3. Frontend Setup

```bash
cd frontend
npm install
npm start
```

Runs on:  
👉 http://localhost:3000

# 🔗 API Endpoints

| Method | Endpoint     | Description        |
|--------|-------------|--------------------|
| GET    | /tasks      | Get all tasks      |
| POST   | /tasks      | Create new task    |
| PUT    | /tasks/:id  | Update task        |
| DELETE | /tasks/:id  | Delete task        |
